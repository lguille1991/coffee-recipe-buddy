# Fellow Opus Grind Table

Source model: **Fellow Opus** (Honest Coffee Guide)

- Scale: `1–11` in `0.25` increments

## Recommended Settings by Brew Method

| Brew method | Settings |
|---|---|
| Turkish | N/A |
| Espresso | 1 – 2.5 |
| V60 | 2.75 – 6 |
| Aeropress | 2 – 8.75 |
| Moka Pot | 2.5 – 5.5 |
| Pour Over | 3 – 8.5 |
| Siphon | 2.5 – 7.25 |
| Filter Coffee Machine | 1.75 – 8.25 |
| French Press | 6 – 11 |
| Cupping | 3.5 – 7.75 |
| Cold Brew | 7.25 – 11 |
| Cold Drip | 7.25 – 11 |
| Steep-and-release | 3.25 – 7.5 |
